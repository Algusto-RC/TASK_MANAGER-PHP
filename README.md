# Sistema de Tarefas - PHP

Gerenciador de tarefas desenvolvido em PHP puro, com foco em boas práticas de organização, autenticação de usuários, CRUD e integração com banco de dados MySQL.

## Tecnologias

- PHP
- MySQL
- PDO
- HTML
- CSS
- JavaScript
- Composer

## Funcionalidades previstas

- Cadastro de usuários
- Login e logout
- Cadastro de tarefas
- Edição e exclusão de tarefas
- Filtro por status
- Organização por prioridade
- Integração com banco de dados
- Validação de formulários

## Objetivo

Projeto desenvolvido para praticar fundamentos de desenvolvimento backend com PHP puro, banco de dados relacional, autenticação e organização de código.
